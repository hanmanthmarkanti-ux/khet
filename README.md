# 🌾 Khet Diary

**Farm & Home Tracker for Indian Farmers**

A free, all-in-one web app built for Indian farmers to manage crops, track farm business, control home expenses, and boost profits — all from their phone.

🔗 **Live App:** [https://khet-diary-76200.web.app](https://khet-diary-76200.web.app)

---

## 🚀 Features

### 🌱 Crops Management
- **Add & Track Crops** — Rice, Cotton, Chilli, Groundnut, Maize, Sugarcane, Turmeric, Onion, Tomato, and more
- **Per-Crop Expense Tracking** — Seed cost, fertilizer, labour, and other expenses per crop
- **Revenue & Profit Calculator** — Auto-calculate net profit per crop and per acre
- **Crop Records** — Filter by status (Growing / Harvested / Sold / Failed)
- **Export to CSV** — Download crop data anytime

### 🌤️ Weather & Rain Alerts
- **Live Weather** — Real-time temperature and conditions using Open-Meteo API
- **7-Day Forecast** — Plan your farming activities ahead
- **Rain Alert** — Get a **30-40 minute advance warning** before rain starts using hourly forecast data

### 🧪 Farm Inputs Tracker
- Track **Fertilizer, Pesticide, Seed** usage and costs
- Brand / name, quantity, unit, and cost per entry
- Total spending summary by input type

### 📊 Market Prices
- Track **crop prices per quintal** across different markets
- Monitor price trends over time
- Export price data to CSV

### 🌧️ Rainfall Tracker
- Log daily rainfall in mm
- View monthly, yearly, and average rainfall stats

### 📅 Crop Calendar
- Set planting and harvest reminders
- Track upcoming farm events

### 🔄 Crop Rotation Planner
- Plan what to plant next season
- Rotate crops wisely for better soil health

---

### 🏢 Business Module

#### 🚛 Vehicle Management
- Add tractors, harvesters, trucks, rotavators
- Track each vehicle separately

#### 🚜 Farm Work Entries
- Log work done per vehicle — customer name, phone, hours, acres
- Auto-calculate amount (₹/hour or ₹/acre)
- Track received vs pending payments
- Attach photos (receipt, field photos)

#### ⛽ Diesel Tracker
- Record diesel fill-ups per vehicle
- Track litres, price per litre, total cost
- Pump name and notes

#### 💰 Dashboard
- Total received, pending, farm costs, net profit, home expenses
- Vehicle-wise summary

#### 🏠 Home & Income
- Track household expenses (Food, Education, Medical, Bills, Clothing, Transport, etc.)
- Record money that came in (Income, Borrowed, Gift)
- Monthly expense/income summary

#### 🧮 Interest Calculator
- Simple Interest — P × R × T ÷ 100
- Enter principal, rate, time (months/years/days)
- Auto-show results in both months and years

#### 📋 Monthly Report
- Full monthly summary: Farm work, Diesel, Home expenses, Net balance
- Share report as text

#### 👨‍🌾 Customers
- Customer-wise work records
- Track pending dues per customer

#### 💳 Loans & Debts
- Track money lent and borrowed
- Person name, phone, amount, interest rate
- Net balance overview

#### 👷 Labour Management
- Add workers with daily wage
- Mark daily attendance (Present/Absent, hours worked)
- Track total wages paid

#### 📈 Analytics
- Visual charts and insights on farm performance

#### 📄 PDF Bills
- Generate printable bills for customers

#### 💾 Data Backup
- Download all data as JSON backup
- Restore anytime from backup file

- **Quick Buttons** — One-tap answers for Rice, Cotton, Chilli, Fertilizer, Pests, Govt Schemes, Weather, Profit tips

- Eye-friendly dark theme for night use

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| **HTML / CSS / JS** | Single-page app (no framework) |
| **Firebase Auth** | Email/password login & registration |
| **Firebase Firestore** | Cloud database for all user data |
| **Firebase Hosting** | Free hosting with SSL |
| **Open-Meteo API** | Weather & rain forecast (free, no API key) |
| **Web Speech API** | Voice recognition in chatbot |

## 📱 How to Use

1. Open [khet-diary-76200.web.app](https://khet-diary-76200.web.app) on your phone or PC
2. Register with your email and password
3. Start adding crops, tracking expenses, and managing your farm!

## 🔒 Privacy

- Your data is stored securely in **Firebase Firestore** (Google Cloud)
- Only **you** can see your data — tied to your login
- No data is shared with third parties
- You can download and delete your data anytime
